# 妙音娘子 · 首版需求

本文记录已确认的产品范围，作为后续开发和验收依据，不表示相关功能已实现。

## 1. 定位与技术栈

- macOS 本地桌面音乐播放器，界面清爽，借鉴 Spotify 的布局与交互气质。
- Wails v2 + Svelte 5 + TypeScript + shadcn-svelte + Tailwind CSS v4。
- 动效丰富但服务于状态和操作反馈，尊重系统减少动画偏好。
- 核心功能：推荐、搜索、播放、下载；附带本地收藏与音源管理。
- 不做登录、注册、云同步、自建歌单或社交功能。
- 推荐、搜索、播放和下载只使用 QQ 音乐，不接入其他音乐平台。

## 页面组织

- 主导航：推荐、喜欢、下载、设置。搜索不占侧栏入口，使用主内容区顶部的常驻搜索框；音源位于设置中。
- 设置分区：播放（播放音质、默认音量）、下载（下载目录、下载音质）、音源（导入及启用管理）。右侧连续展示，左侧菜单作为吸顶锚点目录，随滚动高亮，不切换内容。
- 所有页面共用顶部搜索框，不展示顶部路径或右上角音源状态；设置页不展示重复的「设置」标题。
- 前端采用页面和功能组件拆分，主页面按需加载；设置内部连续渲染各分区。页面切换不得丢失设置草稿或取消自动保存。

## 2. 推荐

- 使用 QQ 音乐榜单与新歌，不做账号个性化推荐。
- 首页展示榜单和新歌入口，点击进入曲目列表，不直接铺满歌曲。
- 曲目列表支持播放和批量下载。

## 3. 搜索与详情

- 搜索仅返回歌曲，可输入歌名、歌手或专辑名称。
- 聚焦搜索框不切换页面，在框下展示提示；仅点击搜索按钮、按回车、点击提示或悬停提示后回车才进入搜索页。支持方向键选提示、Esc/Tab/外部关闭；中文输入法确认不误提交。
- 搜索页不展示额外「搜索」页面标签或音源名称；数量仅显示「约 N 首」。
- 历史搜索以 tags 展示，点击可重搜，支持删除和清空；本地持久化、最近优先、去重，最多保存 20 条。
- 搜索结果中的歌手名、专辑名可点击进入对应详情页。
- 歌手页展示简介和热门歌曲，支持播放全部、批量下载。
- 专辑页展示封面、发行信息和完整曲目，支持播放全部、批量下载。

## 4. 播放与队列

- 点击歌曲立即播放，当前列表成为播放队列。
- 支持顺序播放、随机播放、单曲循环、上一首、下一首、进度拖动与音量控制。
- 顺序播放按队列首尾循环；上一首始终切歌，不执行超过三秒先回曲首的规则。单曲循环仅影响自然结束，手动切歌仍按队列；随机下一首提前确定，上一首使用实际播放历史。
- 三槽缓存：当前边播边完整缓冲，相邻项保留可解码前约五秒并预热；切歌提升新当前、裁剪旧当前，释放非邻居。完整后定位/循环不读上游；不承诺未就绪或物理输出零延迟，具体安全降级与资源边界见 [缓存说明](cache-plan.md)。
- 支持查看队列、移除单曲和清空队列。
- 「下一首播放」调整队列，不打断当前歌曲。
- 重启恢复队列、当前歌曲和播放进度，但不自动播放。
- 点击 macOS 红色关闭按钮后继续播放，点击 Dock 图标可重新打开窗口；⌘Q 完全退出。

## 5. 正在播放与歌词

- 点击底部播放器的专辑封面或歌曲名进入「正在播放」页面。
- 展示封面与滚动歌词，歌词仅逐行高亮。
- 点击歌词行可跳转对应播放进度。
- 不做逐字高亮、翻译显示或桌面悬浮歌词。

## 6. 喜欢的音乐

- 只维护一个本地「喜欢的音乐」列表，不做自建歌单或云同步。
- 按收藏时间倒序排列。
- 点击爱心收藏，再次点击取消收藏。
- 取消收藏不删除已下载文件。
- 支持播放和批量下载整个收藏列表。

## 7. 音源管理

- 首版仅支持从本地导入洛雪兼容 `.js` 音源脚本。
- 导入后保存独立副本，删除或移动原文件不影响后续使用及切换。
- 每次导入成功后自动离线校验（包括重复导入），后续支持手动校验；失败保留副本，不自动启用。界面统一使用「校验」文案。
- 可以保存多个音源，同一时间只启用一个，支持禁用。
- 仅使用脚本的 QQ 音乐（tx）能力。
- 音源失效时明确提示，由用户手动切换，不自动切换其他音源。
- 脚本负责地址解析，不假设其提供搜索、推荐或歌词能力。
- 用户脚本及其中的密钥不复制进代码仓库，也不随应用分发。

## 8. 音质

- 播放音质和下载音质分别设置，互不影响，均默认「最高可用」。
- 设置列表展示当前启用音源支持的普通无损、有损音质，不显示杜比、母带等特殊音质。
- 「最高可用」优先普通无损，其次 320K、128K 等有损档位。
- 目标音质不可用时逐级降级，并提示实际播放或下载的音质。
- 不以文件扩展名冒充真实音质。

## 9. 下载

### 默认设置

- 默认目录为系统「下载」目录，不额外创建「妙音娘子」子目录。
- 设置中可修改下载目录、默认下载音质。
- 设置修改停止 1000ms 后自动保存，连续修改重新计时；成功后右上角绿色 toast 提示，失败显示红色 toast，不提供手动保存按钮。
- 目录选择器从表单当前选中的目录打开，不必等待自动保存完成。
- 单曲和批量下载均遵循创建任务时的下载音质与目录设置；之后修改设置只影响新任务。
- 文件名采用 `歌手 - 歌名 [音质].扩展名`。

### 批量下载与本地核对

- 支持批量下载整个榜单、收藏列表，以及歌手页和专辑页的曲目。
- 下载前只检查当前下载目录，不扫描整台电脑，也不将播放缓存计入本地歌曲。
- 使用 QQ 音乐曲目 ID、音质记录及文件实际存在情况判断，不仅比较文件名。
- 本地已有目标或更高音质版本且验证通过时，仅 toast 提醒，不新增跳过记录；已有低音质版本时下载更高音质版本，保留原文件。
- 记录存在但对应文件不存在时，不得直接跳过。
- 保留任务级进度与批量取消，不显示“最近一批”摘要及整体进度条；暂停后继续的准备阶段保留已有进度。
- 单曲失败不阻塞其他歌曲；状态通过列表和分类查看，可重试失败项。

### 下载页 Tabs

| Tab | 展示范围 |
| --- | --- |
| 全部 | 全部任务，含等待中、下载中、下载成功、下载失败、已跳过、已取消 |
| 下载中 | 正在下载、已暂停及保有进度的续传准备任务，不含新建等待项 |
| 下载成功 | 已成功完成的任务 |
| 下载失败 | 已失败的任务，支持重试 |

等待中、已跳过、已取消仅出现在「全部」，不计入成功或失败。正在下载时，在音频已下载/总体积后显示按已确认字节增量测得的下载速度；暂停或准备中不显示速度。

### 记录与文件删除

- 移除下载记录默认不删除本地歌曲文件。
- 另提供明确的「删除本地文件」操作，执行前二次确认。

## 10. 实现约束

- 接口失败、空结果、加载中、音源禁用和音质降级均需明确反馈，不伪造成功。
- 音源运行器必须隔离本地文件、系统命令与 Wails 桥接，限制网络请求及执行资源。
- 应用私有数据需要持久化设置、音源副本、收藏、播放恢复状态和下载记录。
- 仅在获得必要授权并符合服务条款的前提下使用音乐和下载能力。

## 11. 待实现时验证的边界

以下内容尚未确定，不视为已确认需求：

- 无损细分档位（例如普通 FLAC 与高采样率无损）的具体白名单及优先级，需结合音源和 macOS 解码能力验证。
- 无应用记录的既有歌曲文件如何可靠识别曲目 ID 和音质；不得仅凭名称猜测后直接跳过。
- 歌词缺失或无时间轴、歌手及专辑数据缺失时的展示回退。
- 移除当前播放曲目、清空队列时是否继续播放当前歌曲。
- 下载生命周期已确认：退出保留临时文件，重启不自动下载；用户继续时重新解析，校验媒体实体一致后才断点续传，否则从头下载。具体约束见 [下载说明](downloads.md)。

## 12. 开发顺序建议

1. 本地持久化、音源导入副本和启用管理、隔离解析运行器。
2. QQ 音乐搜索、榜单、新歌、歌手与专辑数据适配。
3. 播放队列、音质降级、正在播放与歌词、本地收藏及恢复。
4. 下载任务、目录核对、音质升级、分类与批量操作。
5. macOS 窗口生命周期、异常处理与端到端验收。
