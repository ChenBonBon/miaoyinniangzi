# 三槽播放缓存

状态：已接入应用，macOS 自动化及真实音源验证通过，实际客户端听感仍待验收。不承诺严格零延迟。

## 行为

- 当前曲目取得初始数据即可准备播放，同时后台完整下载，不等待整曲完成。下载按 256KiB 分块，完整后定位/循环从私有磁盘读取，不再请求源媒体。
- 上一首、下一首先解析并缓存覆盖前约五秒的完整音频帧及原始解码头，再创建暂停、静音且已等待初始输出准备回执的 libmpv 实例。下一首优先于上一首准备；尚未准备好时仍可能等待。
- 切歌优先移交已准备的原生实例；新当前项开始完整缓冲。旧当前项若仍为邻居，截断到开头帧边界；其余文件、代理及预热播放器释放。一首/两首队列去重，至多三项。
- 顺序首尾循环，上一首始终切歌。单曲循环仅改变自然结束。随机下一首稳定预选，上一首沿实际历史；无历史不预取上一首。模式改变可更新邻居，使用独立版本号拒绝乱序更新。
- 暂停保留后台整曲下载；明确取消解析/缓冲会清空缓存。普通切歌不清空三个槽。切源、禁用/删除/重查源、关闭会撤销缓存；新音质使用独立键，不复用旧音质。

## 一致性与边界

- 键包含音源 ID、请求音质、QQ MID，每项固定实际音质、探测容器、文件大小与最初解析地址；不以歌名识别数据，不拼接新旧 URL。
- 合并分块要求已知大小、Range 支持和强 ETag；每次响应必须为精确 206、相同 Content-Range 总量、长度和强 ETag。缺少这些条件或磁盘无法创建时保留原有流式路径，当前项提示“无法建立磁盘缓存”，不宣称整曲缓存成功。后续下载错误可能使整曲缓冲未完成，可通过状态接口确认。
- 不完整项五分钟后重新解析并丢弃旧数据；媒体错误后重试同样重新建立项。已完整缓存可继续本地读取，不因签名地址过期而主动丢弃。
- MP3 按实际帧头逐帧累计时长，兼容变码率，留少量解码余量。FLAC 解析元数据、帧号/样本号，并校验 CRC8/CRC16 后确定切点。不按固定码率估算，不把截断前缀当作独立完整文件；代理始终报告原始完整大小，缺失区域受控读取上游。
- 未识别的前缀不能伪称已就绪；邻居准备失败不打断当前曲播放。切歌过快、地址失效、网络/磁盘失败时无法保证免等待。

## 资源与安全

- `internal/songcache` 使用系统临时目录中随机 `miaoyin-song-cache-*` 目录（0700）和无歌曲标识的文件（0600），不进入下载记录或 SQLite。正常淘汰/关闭删除；后续启动首次使用缓存时，后台清理具有有效 PID 标记且所属进程已退出的残留。Windows 权限及清理行为仍待真机验收。
- 当前最多 512MiB；每个前缀探测上限 32MiB，正常就绪后裁剪为帧边界。邻居的额外元数据读取仅用有界响应缓冲，不重新增长被截掉的尾部。三个文件逻辑上限合计 576MiB；不包含解码器内存、临时响应、文件系统快照或短暂退出中的资源。
- 共用最多四个上游读取槽，预取最多占三个，为当前解码器留下一个槽；同块读取合并。音源解析串行，前台换曲取消其他未就绪项，避免邻曲解析抢占当前源请求。
- 文件读取仍经 Go 受控网络/不透明 loopback，播放器只见本地地址。原始 URL、ETag、文件路径、脚本与鉴权不进入前端或诊断。代次检查覆盖切歌、取消、源失效及晚到结果。
- 相邻预取会消耗真实音源额度与少量媒体流量；当前整曲后台缓存会主动读取完整媒体，即使暂停后也继续。它不是下载功能，也不是媒体解码沙箱。

## 观测与验证

- `GetPlaybackCacheStatus` 仅返回当前/邻居的准备状态、有效字节数、总量、前缀大小、完整标记和预热播放器状态；邻居数组无顺序承诺，不含任何 ID、地址、路径或标签。当前播放器已交给应用时，槽中的 `playerReady` 为 false，不表示当前未播放。
- 本地诊断增加 `cache_prepare` / `cache_reuse`。后者表示已有项被使用，可能仍在准备，不等于零等待；不把背景预取的旧耗时归到新播放请求。
- 单元/race 覆盖整曲后定位无上游读取、完整帧裁剪、尾部不再增长、强 ETag 变化拒绝、并发合并、三槽提升/降级/清理、陈旧会话与模式更新失效、流式降级、当前读取容量预留。
- 显式静音原生测试覆盖合成 FLAC/320K/128K：复用已准备实例，整曲缓存后反复定位不读取上游。
- `MIAOYIN_LIVE_THREE_SLOT_CACHE=1`、`MIAOYIN_SOURCE_TEST_PATH`、`MIAOYIN_MPV_LIBRARY`，可运行 `TestProvidedThreeSlotCacheLive`；`MIAOYIN_CACHE_TEST_QUALITY` 选择普通音质。真实三曲的 FLAC、320K 已通过整曲、前缀和准备实例切换测试。默认跳过，以免消耗额度/流量。
- 这些是字节缓存、原生回执和静音设备测试，不是扬声器 PCM 捕获；最终仍需在 `build/bin/妙音娘子.app` 检查实际切歌和歌词定位听感。
