# 浏览导航

搜索框左侧固定放置后退、前进、刷新三个图标按钮，支持键盘焦点、可访问名称及悬停提示。推荐页目录及曲目页不再单独放刷新图标，错误态的重试入口保留。

## 历史

`navigation.svelte.ts` 维护最多 100 条会话内记录，不写入磁盘，不借用音乐播放队列。主导航点击、显式搜索、搜索分页、榜单目录/详情/分页、收藏分页、下载分类/分页、设置锚点和播放详情进入均经过同一入口。重复点击当前主导航不增加历史；在后退后打开其他页面会截断前进分支。

历史保存页面、当前页自己的浏览快照及内容滚动位置：

- 推荐：具体榜单、页码和目录/列表位置，优先使用已有的有界元数据缓存。
- 搜索：提交的关键词、页码和结果快照。已成功结果返回时不重新请求；未完成的搜索恢复时仅重新请求元数据，旧回执不能覆盖恢复结果。单纯聚焦或输入不导航。
- 喜欢、下载：页码；下载同时恢复分类，但不恢复复选框勾选，避免误操作。
- 设置：锚点和位置，不拷贝或回滚设置草稿。
- 正在播放：只恢复歌词浏览位置/跟随状态，不恢复历史歌曲、进度或队列，不触发播放。

页面通过 `mountNavigationPage` 提供 capture/restore/refresh 适配器；父导航不静态导入各页面或控制器，保持懒加载。代次、当前条目和适配器所有者共同拒绝迟到恢复，尚在加载的页面也可后退或前进；不会因旧请求结束重新滚动或抢回页面。播放详情的返回同样使用浏览历史。

## 刷新

刷新不增加历史记录，不重载整个 WebView，也不会启动媒体解析、播放、下载、源脚本检查或音源自动切换：

| 页面 | 更新内容 |
| --- | --- |
| 推荐 | 当前目录或当前完整榜单元数据 |
| 搜索 | 已提交关键词的当前页，不把未提交输入当成新搜索 |
| 喜欢 | SQLite 收藏列表 |
| 下载 | 本地任务状态，不继续暂停任务 |
| 设置 | 持久化设置及音源列表；存在待保存、保存失败或目录选择时拒绝刷新，保留草稿并提示先完成保存 |
| 正在播放 | 当前歌词，绕过歌词缓存；保持当前音频和队列 |

刷新期间禁用重复刷新。换页后旧页面的刷新不会锁住新页面或显示迟到错误。当前无可用历史方向时，对应后退/前进按钮禁用。所有历史仅存于当前应用前端会话，重启不恢复浏览历史。

验证覆盖主导航分支、搜索快照及迟到请求、榜单分页和滚动、加载中前进/后退、下载页码与勾选清除、设置草稿保护、播放期间刷新及窄窗口。浏览器验证不替代实际 `.app` 体验验收。
