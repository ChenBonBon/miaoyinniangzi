# 下载

## 已接入

- 搜索结果提供单曲下载和「下载本页」；喜欢页面、推荐的榜单/新歌曲目页提供单曲下载和「下载全部」。歌手详情可下载热门歌曲，专辑详情可下载完整专辑，均复用已有任务安全校验及去重。
- 新任务读取并固定当时的下载目录和音质，后续设置修改只影响新任务。目录解析为当时的实际绝对路径，不扫描其他目录。
- 下载独立于播放和三槽缓存：有独立解析取消通道，不能取消正在准备的播放；不将播放缓存当作本地歌曲。当前只运行一个下载任务，其他任务等待，单项失败继续处理后续项。
- 默认直接使用系统下载目录，不创建额外产品子目录。文件名为 `歌手 - 歌名 [音质].扩展名`，非法字符及路径分隔符替换、限制字节数；重名使用序号，绝不覆盖。
- 初始媒体探测验证 FLAC/MP3 和大小，不把扩展名当格式。MP3 完成后扫描实际帧计算码率；无法确认普通档位时标记通用 MP3，不用于跳过后续 320K/128K 目标。FLAC 是实际容器验证，不承诺高采样率细分或授权判断。

## 续传与退出

- 退出保留隐藏临时文件 `.miaoyin-<随机任务ID>.part` 和已同步检查点。启动将未完成任务恢复为暂停，不重新解析、不联网；用户点击继续或重试才开始。
- 继续前重新解析当前启用音源，校验来源、实际音质、容器、总大小、**强 ETag** 和完整资源地址指纹；临时文件检查点还需通过本地 SHA-256 校验。不能仅凭名称、MID、长度或相同歌名决定拼接。
- 地址指纹是完整资源地址（包含查询参数）的 SHA-256，不保存地址本身。签名变化、换 CDN、来源或 ETag 变化时，即使可能仍为同一音频，也保守地从头下载，不冒险拼接。弱/缺失 ETag 只进行单响应完整下载，重试从头开始。
- 已确认的同一实体使用精确 Range 和检查点续传；每次检查 HTTP 状态、Content-Range、长度、ETag，并拒绝超出预期的响应。写入与同步后更新检查点；异常退出丢弃最后未确认尾部，而不是信任文件大小。
- 临时文件被外部修改时失败并保留，不截断修改后的内容。普通实体不匹配则清空已确认属于任务的旧前缀，显示从头下载原因。
- 暂停保留检查点，可手动继续。取消后移出列表并清理应用自有、校验通过的临时文件，不保留可继续的记录。音源切换、禁用或重查时暂停活跃和等待任务，不自动换源续下。首次解析/下载最多 20 分钟，最多 512MiB；失败不自动重试。

## 去重与完成

- 使用当前任务目录内的应用下载记录、QQ MID、实际音质、文件真实存在情况、大小和完整 SHA-256 核对。目标或更高音质已存在且未变化时，仅 toast 提示，不新增下载记录；低音质升级保留原文件。解析后才确认目标降档而发现重复时，也会移除临时任务记录并提示，不留“已跳过”条目。
- 无应用记录的旧文件不凭名称猜测，不覆盖；记录存在但文件缺失、被更名或发生变化时，不跳过。
- 完成采用同目录、不替换目标的原子重命名发布，不再依赖硬链接。macOS 使用目录句柄相对的 `renameatx_np(RENAME_EXCL)`，Linux 使用 `renameat2(RENAME_NOREPLACE)`，Windows 使用目录/源文件句柄相对的 NT FileRenameInformation（ReplaceIfExists=0），不使用允许替换的回退操作。名称竞争、既有文件或目录均不能被覆盖；冲突沿用编号命名。
- 发布前持久化完整字节哈希和源文件身份（卷/文件 ID，以及平台可用的创建/修改时间），检查当前目录仍与已打开的目录一致，发布后核对身份和完整字节，再记录成功。数据 Sync 后尝试目录 Sync；部分文件系统不支持目录 Sync，不将其等同于可以覆盖目标，也不保证突然断电/强拔下的绝对持久性。
- 发布完成但数据库成功写入失败时，重启不联网，用户手动继续可依据身份加完整哈希认领本任务的落盘文件。完整临时文件因空间、权限或发布能力问题失败后，也可在手动重试时只重试本地发布，不重新解析签名地址。仅哈希相同、文件名相同不证明目标归属；身份或内容变化则失败，绝不覆盖、拼接或删除未知文件。卷重新挂载后若文件身份不能稳定确认，会保守拒绝认领。
- 当前未承诺跨进程实时任务协调。多个应用实例或外部程序更改文件时仍做存在/哈希检查，安全失败优先于覆盖。

## 下载页

四个 Tabs：全部、下载中、下载成功、下载失败。「下载中」包含实际传输项、已暂停任务和保有进度的续传准备项，避免点击继续时整行消失；新建等待和历史跳过只出现在全部；已取消项不显示。列表沿用搜索/喜欢页的表格、封面、歌名和歌手样式，展示状态、字节进度和实际音质，目录与文件名放在歌曲提示中。支持暂停、图标式继续/重试，以及全局和所选任务操作；续传准备阶段仍显示此前确认的进度，不伪造前进。暂停时不重复显示“等待手动继续”。下载速度显示在进度条下方的已下载/总体积之后，以单调时钟和两次已确认字节数计算采样区间平均速度；首次采样显示“测速中”，暂停、准备、完成或字节回退时清除旧测速，不将暂停耗时计入续传速度。

不显示“最近一批”摘要或整体进度条，已移除“取消本批”按钮。右上角固定显示“全部开始”和“全部暂停”，作用于所有现有任务，不受分类、页码、批次限制：“开始”仅将暂停、失败项加入等待队列；“暂停”覆盖传输与等待项；成功、跳过任务保持不变。

表格增加逐项复选框和“全选本页”，支持半选与键盘空格。只有存在勾选任务才显示“开始／暂停／取消”，各操作仅针对所选且适用的任务，不适用时禁用。取消停止等待、传输、暂停或失败任务并立即移出列表，不影响成功任务或已完成文件。运行中的任务持久化取消状态后先隐藏，待工作线程释放文件再安全清理临时文件和记录；旧版本已取消项及意外退出遗留状态在启动时清理，不会恢复到列表。仅删除校验通过的应用自有断点，不删除外部修改或无法验证的文件。操作成功清空选择，失败保留选择；切换分类或页码清空勾选，避免误操作不可见项目。

批量操作通过 `ControlDownloads(ids, action, all)` 一次提交，所有状态先在单一数据库事务持久化再应用、唤醒/取消工作线程，失败不产生部分状态变更。空选择不会隐式变成全部；校验动作、ID 和最多 10000 条。快速暂停再开始会保留重新排队意图，旧请求的取消回执不覆盖为失败。任务目录、质量及断点快照不变。

任务记录每页 50 项，页面可见期间读取本地状态，不自动启动任务。

默认「移除记录」不删除已下载文件；未完成记录移除时仅清理校验通过的应用临时文件。另有「删除本地文件」二次确认，删除前重新核对普通文件、大小和哈希；文件已改变或缺失时拒绝删除。无法保证系统快照的安全擦除。

## 存储、安全与边界

- 下载记录使用现有 schema 4 的 `state` 表独立 `download:<ID>` 键，不迁移或重置已有数据。批量创建在一个事务中提交，写入失败不启动部分任务。最多 10000 条记录。
- 私有记录保存续传验证信息；Wails 只返回任务 UI 元数据和进度，不返回地址、ETag、来源 ID 或检查点哈希。不会记录脚本、密钥、歌曲信息或签名地址到诊断日志。
- 媒体联网沿用 Go 公网校验、DNS/IP 固定、重定向限制及 Fake-IP 兼容；不向播放器/前端交付签名地址或源鉴权。
- 文件操作使用受目录约束的 `os.Root`，拒绝临时/完成文件符号链接和非普通文件；修改目录后新任务才使用新位置。存储损坏使下载服务报错，不清空记录，也不阻断播放器启动。
- 新建临时文件请求 0600；exFAT/FAT 等文件系统未必提供 POSIX 权限。安全发布不再要求硬链接，但仍要求系统/文件系统支持不可替换的原子重命名及可验证的文件身份；缺失能力时明确失败、保留数据，不能退回普通替换 rename 或公开目标的逐字节复制。
- 空间不足、设备/目录不可用、只读/权限、发布能力不足和落盘文件变化分别提供固定可操作提示，不展示原始文件系统路径或媒体地址。磁盘拔出不自动联网重试，重新连接后用户手动继续；设置仍只影响新任务。已有断点丢失时不在替代目录新建同名临时文件。
- Windows amd64/arm64、Linux amd64已通过编译检查，不代替文件系统实机测试。当前环境禁止 `hdiutil` 创建/挂载测试镜像，因此本轮 exFAT 真实卷验证尚待外置盘验收，不能把 APFS/故障注入结果当作 exFAT 实测。
- 不改写音频标签、转码、音量或播放定位。仅在具备必要授权并符合服务条款时使用下载能力，不绕过平台限制。

## 验证

Go race 测试覆盖真实落盘、碰撞不覆盖、目录内去重/低档升级、缺失文件重新下载、记录删除不删文件、外部修改拒绝删除、重启手动继续、同实体断点、变更实体/无强 ETag 从头下载、篡改临时文件拒绝、URL 不落库、符号链接拒绝、批量提交失败不执行、MP3 实际档位，以及播放/下载解析相互独立。

挂载外置盘后的显式文件系统验收（只创建独立随机临时子目录，不改动目录中原有文件）：

```sh
MIAOYIN_DOWNLOAD_TEST_DIRECTORY="/Volumes/你的磁盘" go test -v ./internal/downloads -run '^TestExternalFilesystemDownload$'
```

该测试使用本地合成音频，不接触音源或网络，验证整曲落盘、未知文件冲突保护、字节完整性、去重及临时名移除。默认跳过；本轮已在本地文件系统验证脚本，真实 exFAT/FAT/NTFS 需在对应卷执行。故障注入另覆盖磁盘不足/离线/不支持发布、断点外部修改、目录替换、成功记录写入失败后离线恢复及并发目标名竞争。

显式 `MIAOYIN_LIVE_DOWNLOAD=1 MIAOYIN_SOURCE_TEST_PATH=... go test -v ./internal/sourceruntime -run '^TestProvidedDownloadLive$'` 进行真实音源整曲下载和原子发布测试，默认跳过以免消耗额度与流量；已分别通过 FLAC、320K、128K 测试（`MIAOYIN_DOWNLOAD_TEST_QUALITY` 选择档位），不输出地址或识别性元数据。

浏览器 mock 只验证桥接和 UI，不证明真实文件已下载。最终仍需真实 `.app` 验收暂停、退出再继续、音质降级与目录切换；Windows 真机按既定计划留到全部开发结束后。
