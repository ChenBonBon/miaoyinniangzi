# 本地音源导入与加密副本

## 本轮范围

支持 macOS 原生文件选择、静态元信息读取、加密导入、重复检测、列表与 shadcn-svelte AlertDialog 确认删除。导入成功后自动离线校验（重复导入也校验），不自动启用；后续支持手动校验。失败保留副本。单选启用和禁用详见 [运行器](source-runtime.md)。仅校验通过的音源可选，当前项提供禁用操作，不提供列表外的全局开关。

## 存储

SQLite schema v2 新增 `sources` 表（v3 增加检查和选择状态），元信息和 AES-256-GCM 密文在同一条 INSERT 中原子保存。加密副本保存在数据库中，不另建明文或密文 `.js` 文件；这是对早期独立文件方案的调整，以避免跨文件与数据库提交产生孤立副本。

- AES 密钥：32 字节安全随机数。macOS 保存到 Keychain；Windows 经当前用户 DPAPI 保护后保存，不写入明文密钥。
- 每次加密使用独立的随机 nonce，记录 ID 作为关联数据，防止不同记录之间交换密文。
- Keychain service：`com.miaoyinniangzi.sources`，account：`aes256-gcm-v1`。
- macOS 使用原生 Security framework，不把密钥放在 shell 参数、SQLite 或配置文件中。
- 禁用钥匙串同步，标记为本设备解锁后访问；保留系统默认访问控制，不授权所有应用读取。
- 密钥不存在且已有副本时，不自动生成替代密钥。新增导入前验证已有密文可用，避免静默换钥匙。
- Keychain 锁定、拒绝授权、密钥异常或加密失败时拒绝导入，不降级成明文存储。
- 应用数据目录权限 `0700`，数据库 `0600`。

首次导入可能触发 macOS 钥匙串授权。开发版二进制或签名变化也可能重新触发授权。密钥丢失后无法恢复密文；需要删除不可用副本并从原始脚本重新导入。

## Windows DPAPI

Windows 密钥接口使用 `CryptProtectData` / `CryptUnprotectData`，仅当前用户模式，不使用 `CRYPTPROTECT_LOCAL_MACHINE`；设置 `CRYPTPROTECT_UI_FORBIDDEN`，不要求 PIN 或系统交互，失败不降级到明文。

DPAPI 保护后的密钥保存到应用数据目录中的 `source-key.dpapi`，文件创建时设置仅当前用户和 SYSTEM 可访问的受保护 DACL，不依赖 Windows 上的 `chmod`。同目录私有临时文件写入、同步、关闭后原子发布，不覆盖已有密钥；并发首次创建使用胜出文件。读取有大小限制，拒绝空文件、损坏数据、目录和文件重解析点，异常时不重置密钥。已有音源但密钥缺失时，导入管理器不会生成替代密钥。

同一 Windows 用户下的其他进程可能调用 DPAPI 解密可取得的 blob，这不是应用级授权或 Windows Hello 门禁。跨用户/跨设备复制数据不保证可解密；漫游/域恢复行为由 Windows 策略决定。密钥只在主进程内使用，不交给音源 worker。

已完成 Windows amd64/arm64 包及测试的交叉编译。Windows 专用测试覆盖 DPAPI 往返、重开稳定性、DACL 保护、损坏不覆盖和并发创建；这些测试尚未在 Windows 运行。macOS 既有测试通过。Windows 音源隔离仍待实现，因此本次不代表 Windows 整端可用。

## 验证与元信息

- 仅接收 `.js` 普通文件，拒绝符号链接、空文件、超过 1MB 的文件、非 UTF-8 或含 NUL 的数据。
- 读取前后检查文件身份，并对实际读取量设置上限。
- 只读取前 16KB 内完整的起始块注释中的 `@name`、`@author`、`@version`，过滤控制字符、限制字段长度；无名称时使用文件名。
- 不保存 description、原始路径或脚本正文到元信息。名称、作者及版本属于未加密展示信息，请勿在这些字段中放置秘密。
- SHA-256 用于内容去重，只保存在本地；重复内容不覆盖已有记录。相同名称但内容不同的脚本独立保存。

## Wails 边界

- `GetSources()`：只返回 ID、名称、作者、版本、导入时间。
- `ImportSource()`：自行打开原生文件选择器，前端不能传入任意路径；取消返回 null。保存成功后由后端自动校验并返回状态；导入与校验错误分开处理，校验失败不删除已保存副本。
- `DeleteSource(id)`：前端 AlertDialog 确认后才调用，后端校验存在性并执行删除，不再弹原生 MessageDialog。只删除应用中的元信息和密文，不删除原文件。删除中禁用重复提交和关闭操作；失败保留弹窗并允许重试，成功关闭，焦点返回列表操作或导入按钮。
- `CheckSource`、`ActivateSource`、`DisableSource` 提供离线检查与选择管理，返回元信息及检查/启用状态，不返回运行器对象。
- 不向前端暴露密文、解密方法、密钥、哈希或原始路径。日志和导入错误不包含脚本正文。
- 数据库迁移失败时事务回滚，原有设置与收藏不受影响。

## 安全边界

加密可防止单独拷走数据库后直接读取脚本内容，不是 DRM。它无法抵御已控制用户会话的恶意软件、管理员或调试器。原始脚本仍是明文，须由用户自行保管。解密及导入只在内存处理。启动后可提前读取系统密钥并解密当前启用源，主密钥用后尽力清空；当前启用的脚本副本为减少重复解密保留在主进程内存（最多 1MiB），不执行或联网。解析使用独立快照并用后清空。切换、禁用、删除、重查当前项和关闭会清理缓存，过期授权结果不能恢复旧缓存；激活/检查仍重新读取真实密钥、解密并校验，不信任缓存。Go 和系统库的内存副本无法保证完全擦除。删除密文也不等于物理擦除磁盘或已有备份。

## 测试

Go 单元测试使用临时数据库和注入的假密钥提供者，不访问真实用户钥匙串。覆盖加解密、错钥匙、截断/篡改/记录交换、内容去重、同名不同内容、原始文件删除后恢复、无明文/密钥落盘、非法文件、Keychain 失败、数据库迁移和插入失败原子性。

Playwright 使用 Wails mock，覆盖导入、取消、去重提示、列表状态、确认删除及取消删除。真实 Keychain 授权与 macOS 原生对话框仍需人工验收。
