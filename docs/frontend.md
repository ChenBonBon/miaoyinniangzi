# 前端组织与按需加载

## 页面结构

主导航包含推荐、喜欢、下载、设置；喜欢是独立的本地收藏页面，按需加载。搜索是内部页面，通过主内容区顶部的常驻输入框进入；聚焦输入框只展开当前关键词、匹配历史和 QQ 歌曲下拉提示，保持当前页面与滚动位置；显式提交或选中提示后才切入搜索页。支持悬停后回车、方向键、Esc、Tab 和外部关闭，中文输入法确认不误提交。搜索页保留历史 tags。音源位于「设置 / 音源」，推荐页不再提供配置按钮。搜索框左侧有统一的后退、前进、刷新工具栏，详见 [浏览导航](navigation.md)。

所有页面共用顶部搜索栏，不展示顶部路径或音源状态；设置为连续滚动页面，无额外「设置」标题。左侧目录吸顶，点击滚动定位，随阅读位置高亮；保留独立的分类组件，但不再切换或卸载其他分类。

页面底部不设置分区最小高度来凑齐锚点位置，不显示常驻自动保存说明；仅在保存失败时保留重试入口，成功反馈使用 toast。

设置项使用 `SettingRow.svelte` 统一布局：左侧名称与描述，右侧控件，行间使用 Separator。右侧控件列宽一致；设置内容区域不足 36rem 时自动上下排列，不根据整个窗口宽度盲目判断。目录路径可悬停查看完整值。

设置分区：

- 播放：播放音质、默认音量。
- 下载：下载目录、下载音质。
- 音源：本地脚本导入、列表和删除，不提供独立的全局启用开关。每次导入后自动离线校验，列表保留手动校验按钮；只有本地兼容性校验通过后才能单选启用，当前项支持禁用，不伪造未完成的启用状态。不展示音乐平台设置，QQ 音乐限定保持不变。

## 性能边界

- 使用显式 `import()` 加载四个主页面，Vite 生成独立代码块；设置内部三个分区随设置页面一起加载，保证连续阅读，不为这部分小表单过度拆包。
- 仅渲染当前主页面；设置内三个分区同时渲染。顶部搜索栏、底部播放器常驻，中间 `[data-content-scroll]` 独立滚动，窄窗口也不将播放控件滚出视口。
- 设置模块及其数据只在首次进入设置时加载，不在首页提前查询数据库。
- 设置草稿和保存控制器属于应用生命周期，离开设置不销毁计时器；重新进入不重复读取并覆盖草稿。
- 搜索输入、结果及推荐浏览使用轻量共享状态，卸载组件不会清空；QQ 搜索按每页 20 首渲染，图片懒加载，新请求取消旧请求，详见 [搜索适配](qq-search.md)。
- 共享 UI 代码由 Vite 提取，不能只用入口文件体积衡量首屏总成本。
- 页面加载失败有反馈，切页期间的过期 Promise 不会替换当前页面。
- 不提前引入虚拟列表等尚无数据规模依据的优化；真实曲目列表接入后再按测量结果决定。

## 验证

```sh
cd frontend
npm run check
npm test
npx playwright install chromium  # 首次运行浏览器测试时
npm run test:e2e
```

Playwright 针对生产构建运行，使用测试专用 Wails mock，不读写用户数据库，覆盖：

- 首屏不请求设置代码块、不读取设置。
- 设置没有多余页头，三个分区连续显示，音源不再是主入口。
- 点击锚点和手动滚动均更新目录高亮，适配主内容滚动区和窄窗口的横向目录。
- 宽屏左右布局、窄屏上下布局，无横向溢出；分隔线和音量轨道具有正确尺寸。
- 跨分类修改合并保存，切走后自动保存和 toast 正常。
- 重新进入设置保留值且不重复读取；目录选择器使用当前草稿。
- 推荐页仅展示榜单分组，不再提供类型切换、配置音源按钮或独立刷新图标；顶部搜索输入及统一浏览工具栏保留；聚焦/输入不切页，提示选择与提交才切页，保留输入与原页面滚动位置；结果不显示渠道前缀，仅显示约 N 首。
- 提示的悬停后回车、点击与键盘选择、中文输入法、关闭方式、建议失败降级和建议/完整搜索取消互不干扰。
- Tabs 使用 Bits UI 的 data-orientation/data-state 属性，避免下载分组方向和选中样式失效。
- 历史 tags 重启恢复、去重、点击重搜、逐条删除、清空；历史失败不阻塞搜索，清空后不会因旧查询完成而恢复。
- 自动/手动音源校验、单选切换、禁用、失败重试；切页不中断导入校验，失败保留副本；启用结果成功前不显示选中；音质列表按当前音源过滤，不覆盖已保存偏好。

浏览器测试不替代 macOS WebView 和原生目录对话框的人工验收。
