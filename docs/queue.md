# 播放队列

底栏右侧的队列按钮打开独立侧栏，不切换页面，不重新解析当前歌曲。桌面侧栏与页面并排；窄窗口暂时展示队列，底栏仍可控制播放，进入其他页面会收起队列。

## 操作

- 点击歌曲：切换至该队列项，保留整个队列。当前歌曲已播放时不重启；暂停时继续播放。
- 移除非当前项：保留当前音频实例、位置和暂停意图，重新计算邻曲缓存。
- 移除当前项：按当前模式的下一首选择后继，播放/准备中继续播放；暂停或出错时仅选择后继，保持暂停且不解析媒体。只有一项时清空。
- 清空：确认后停止播放，撤销当前准备/缓存，保存空队列；不影响收藏或文件。
- 下一首播放：搜索结果和队列项均提供入口。已有项移动到当前项之后，不增加副本；队列中的重复歌曲以具体位置区分。空队列只加入并选择，不自动播放。
- 随机模式下，显式下一首优先一次，消费后恢复随机；切换模式仍保留这个优先项。自然单曲循环仍只循环当前曲，不被“下一首播放”打断。显式选择/后退后不沿用旧当前项的优先跳转。
- 随机实际历史、已计划下一首在编辑时按具体队列项重新映射，不因移除其他项而重置；移除的项同时从历史消失。

## 状态与缓存

`player-controller.ts` 管理全部队列变更，不让面板直接写播放状态。队列编辑保留当前有效会话，调用已有 `PrefetchNeighbors` 更新三槽；切换当前项继续走既有 `PrepareSong`。准备期间编辑邻居，准备完成后仍会再同步最新邻居；旧准备回执不得恢复被清空或移除的当前项。

快照继续使用 schema 4 的 JSON。新增可选 `queuedNext` 队列位置，与队列顺序、当前项及进度一起保存，消费/移除后清除；Go 校验其范围且不能等于当前项。旧快照无需迁移；重启仍只恢复暂停状态，不请求媒体。随机完整历史仍仅保留本次会话。

## 界面与可访问性

- 面板按需加载；最大 10000 项，以固定 64px 行和有限窗口渲染，不创建一万个 DOM 行。
- 当前项高亮并显示实际播放/暂停/准备状态。定位按钮回到当前项；当前项切换才自动定位，不随进度轮询重置滚动。
- 原生按钮提供播放、移除、下一首动作；歌曲按钮上可用上下方向键、Home、End 浏览虚拟列表。滚动区域可键盘滚动。
- Escape 关闭面板并恢复入口焦点；确认框中的 Escape 仅取消确认。移除后焦点落到相邻项，清空后落到面板标题。
- 不新增装饰动画，遵循现有 reduced-motion；标题、歌手文本均转义，无 HTML 注入。

## 验证

控制器测试覆盖选择、非当前移除无中断、当前移除的暂停/播放意图、清空与晚到回执、插入/移动、随机历史重映射、重复 ID、10000 项上限、优先项暂停恢复。SQLite 测试覆盖新字段保存重开、非法位置拒绝和旧 JSON 兼容。

Chromium 与 WebKit 覆盖打开/关闭、清空确认与 Escape、搜索加入且不自动播放、邻曲更新、点选播放、移除当前项、窄窗口及 10000 项虚拟滚动/键盘。浏览器桥接测试不代替真实 libmpv 听感，最终仍需客户端验收。
